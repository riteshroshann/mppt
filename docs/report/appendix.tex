\section{Runtime}

The full pipeline takes about \SI{11}{\minute}. The dynamic benchmark of
Chapter~\ref{ch:benchmark} accounts for roughly \SI{6}{\minute} of that, because
it simulates \SI{121}{\second} of closed-loop operation for each of four
trackers, and the switched validation for a further \SI{2.6}{\minute}.
